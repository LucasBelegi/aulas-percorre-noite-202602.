# Box model

O CSS enxerga os elementos do HTML como caixas que possuem algumas propriedades.

## margin
Margem é o espaço que distaancia um elemento do outro, ou seja, é essa medida que faz um parágrafo ir pra longe de uma imagem

## Border
para contornar um elemento podemos configurar uma borda, a borda nada mais é do que uma linha em volta do elemento que fica entre a margin e o padding.

#padding
se a margem é o espaço interno, ele quem separa o conteúdo da borda e da margin.
